# 非官方功能插件 backlog

> 用户 2026-11-07：官方没有的功能，后续抄一些做成插件。
> 定位：GO.1 封版后再做；不阻塞稳定版，不改官方兼容语义。

## 0. 硬规则

1. **官方兼容优先**：先核官方 0.2.2-rc.1 是否已有；已有就复用，不重复造。
2. **只做插件/外围**：不改 `internal/kernel`、Transport canonical、v4/journal/epoch；需要宿主能力时只加 additive 契约。
3. **默认关闭**：每个功能独立开关，可卸载；不能因为插件缺失导致宿主启动失败。
4. **不伪造官方 UI/行为**：没有官方证据就 HIDE；插件入口必须标“扩展”，不冒充官方。
5. **可验证**：每个插件必须有独立测试、失败路径、卸载路径；不以“能加载”当完成。
6. **安全边界**：网络/执行/文件/凭据类插件必须声明 Caps、审批、沙箱策略；默认最小权限。
