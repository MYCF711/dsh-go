# 单点实现登记表 —— 「同一条规则只许有一份实现」的机器可读版本
#
# 由 scripts/single-source.py 读取并扫描；接在 scripts/check.sh 里。
# 这一节回答一个问题：**哪一个判断/哪一种形状，只许出现在一处？**
#
# 格式（一行一条）：
#
#     概念 | 唯一实现 | 形状ID | 为什么这是同一件事
#
#   · 概念      人读的名字，出错时原样打进 FAIL 行
#   · 唯一实现  `路径` 或 `路径:符号`；以 / 结尾表示整个包
#               （守卫会核对它还在：文件/目录不存在，或者 :符号 找不到，直接 FAIL）
#   · 形状ID    由 scripts/single-source.py 实现；这里只登记「哪一条形状归哪个唯一实现」
#   · 为什么    要求能查证：说清「为什么这两处是同一件事」+「多一份会怎么错」
#
# 可选第 5 列：`second=路径:符号`
#
#   登记表如果如实记录了「这条规则现在确实有第二处、而且收不了口」，就写在这里。
#   守卫对登记过的第二处只打 WARN（每次门禁都会打出来，不是橡皮图章），
#   对**第三处**照样 FAIL。第二处消失了却还留着这一列 → FAIL（要求改登记表）。
#
#   为什么会存在第二处：跨包。internal/session 不能 import cmd/dshd，
#   所以它没法调用登记在 cmd/dshd 里的那份。收口的唯一方向是把逻辑下沉到
#   internal/session 并让两边都调它——那要改 .go，不在本轮范围里。
#
# 白名单在 [allow] 段，理由必填。
